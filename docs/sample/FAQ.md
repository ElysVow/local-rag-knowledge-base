# 常见问题 FAQ

## 这个项目需要联网吗？
向量模型首次使用时会从 Hugging Face 下载一次（约 100MB），之后完全离线；大模型通过 Ollama 在本地运行，整个问答过程不依赖网络。

## 对电脑配置有什么要求？
最低配置建议 8GB 内存。运行 7B 参数模型（如 qwen2.5:7b）建议 16GB 内存；如果没有独立显卡，模型会由 CPU 运行，回答速度会慢一些，可改用更小的模型如 qwen2.5:3b。

## 支持哪些大模型？
所有 Ollama 官方支持的模型都可以，常用推荐：
- qwen2.5:7b（中文效果好，通用推荐）
- qwen2.5:3b（低配置机器推荐）
- llama3.1:8b（英文效果好）
- deepseek-r1:7b（推理能力较强）

切换模型只需修改环境变量 LLM_MODEL，或在代码 config.py 中修改。

## 文档内容安全吗？
安全。文档只保存在本地 data 目录，检索与问答全部在本机完成，不会上传到云端。

## 为什么回答会引用无关内容？
可以尝试调低 Top-K 或调高相似度阈值；也可能是文档切分粒度不合适，可以调整 CHUNK_SIZE。

## 如何彻底清空知识库？
在网页左侧点击“清空知识库”，或删除 data/index 目录后重启服务。
