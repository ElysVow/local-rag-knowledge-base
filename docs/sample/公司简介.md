# 星云智能科技有限公司简介

星云智能科技有限公司成立于 2019 年，总部位于深圳，是一家专注于企业级人工智能解决方案的科技公司。

公司现有员工约 380 人，其中研发人员占比超过 60%。核心团队来自国内外知名高校与头部互联网公司，在大模型应用、自然语言处理与知识图谱领域有深厚积累。

公司主营业务包括三类：第一，企业私有化大模型部署与调优服务，帮助客户在本地或私有云环境运行 Llama、Qwen 等开源模型；第二，智能文档与知识管理平台，支持合同、制度、产品手册等资料的自动解析、检索与问答；第三，AI 客服与营销自动化系统，可接入企业官网、小程序与飞书、钉钉等办公平台。

星云智能已服务超过 200 家客户，覆盖金融、制造、零售、教育等行业。代表性案例包括为某大型银行搭建合规文档问答系统、为某制造企业构建设备维修知识库等。

公司愿景是：让每一家企业都能安全、低成本地拥有自己的大模型能力。
